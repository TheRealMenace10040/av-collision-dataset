Open data · California DMV

Every robotaxi crash report, in one table

California required autonomous-vehicle companies to file a PDF form (OL 316) after every collision. This project reads those forms, links them to the federal NHTSA crash reports, and publishes one clean dataset you can search and download.

Sources: California DMV autonomous vehicle collision reports (form OL 316, Oct 2014 to Apr 18, 2026; the DMV has since retired its index page), and NHTSA Standing General Order crash reports for California. NHTSA dates are month-only, so a DMV report is linked to an NHTSA report only when operator, month, time and city all match uniquely; everything else stays unlinked. Personal details (driver names, licence numbers, birth dates, insurance policy numbers, phone numbers) are deliberately not extracted. Fields marked “text-only” came from flattened PDFs where checkbox answers could not be read. Earlier academic work on the same reports: El-Yabroudi et al., Electronics 14(4):651 (2025); Haroon & Ryan (2023).
